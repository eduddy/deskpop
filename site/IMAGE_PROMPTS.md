# Final image generation manifest

The site currently ships with labeled placeholder schematics (generated by
`tools/make_placeholders.py`). To produce the final art, run each command
below **on your Mac, one at a time, sequentially**, from the `site/`
directory. Output paths land directly in `public/images/`, replacing the
placeholders — no code changes needed. Then commit, push, and redeploy.

Shared style, baked into every prompt: aerospace clean-room engineering
aesthetic with cyberpunk undertones — light graphite surfaces, blueprint grid
backdrops, flight-suit orange accents, and the product's actual name printed
legibly on a physical label in the scene. Every image uses a different
dominant accent color and different hardware so all 14 are visually distinct.

## Hero (required, 1536x1024)

```sh
python3 /Users/patsimmons/tools/chatopt-imagegen "Wide aerospace clean-room integration bay interior, light graphite surfaces with faint blueprint grid lines on the walls, a small consultant crew in white-and-orange flight suits inspecting an open avionics rack, warm flight-suit orange accent lighting against cool daylight, subtle cyberpunk holographic readouts floating above a workbench, stencil text OPENTALON BAY 4 painted legibly on the floor, photorealistic, high detail, clean composition with open space on the left for headline text" -o public/images/hero.png --size 1536x1024 --timeout 300
```
